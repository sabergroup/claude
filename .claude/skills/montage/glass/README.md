# ستايل الزجاج (فولدر 4، المعتمد من صابر). نفس الكود ينفع لأي فولدر بتغيير الألوان.

| الملف | بيعمل إيه |
|---|---|
| `pill.html` | الكابشن، والاسم، والترانزيشنز، والقفلة. `DATA` بيتبدل بـ JSON (`filler.data.example.json` مثال كامل). |
| `ins5.html` | الإنسرت الزجاج (`filler.insert.example.json` مثال). |
| `buildp.py` | بيبني الداتا من `words.json` و`edits.json`: تقسيم السطور (`ROWS`)، دمج الكلمتين الإنجليزي (`MERGE`)، الأرقام (`NUM`)، والأصوات (`KEEP`). |
| `glass.py` | الزجاج المضلّع تحت الكبسولة في الكومبوزيت. |
| `compg2.py` | الكومبوزيت: زوم بطيء + `glass.py` + تغبيش الفيديو تحت الإنسرت. |
| `runp3.sh` | الرندر الكامل: فريمات على 4 أنوية، كومبوزيت، أصوات، كريديت أبيض. |
| `rendp.js` | رندر الفريمات. |
| `dbg.js` | بيطبع وقت ظهور واختفاء كل بلوك. |

الصفحات بتدوّر على الخطوط في `../fonts/`. حط الصفحات المتولدة في فولدر جنب فولدر `fonts`، أو انسخ `.claude/skills/montage/fonts` جنبها.
لو هتغيّر الألوان لفولدر تاني: ابدأ بالكحلي #17223F، والتدرج اللي في `.hl` و`.nb` و`.tg` (rgba(58,78,128) → rgba(23,34,63) → rgba(16,24,46)).
